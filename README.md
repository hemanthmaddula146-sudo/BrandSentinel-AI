# BrandSentinel AI

### Protecting Brand Identity. Ensuring Content Integrity.

BrandSentinel AI is an AI-powered platform that helps teams review brand content, identify potentially unsupported claims, and maintain consistent, trustworthy messaging.

## Features

- **AI Content Analysis:** Analyze text using Google's Gemini API.
- **Risk Findings:** Highlight potentially exaggerated claims and statements that need verification.
- **Review History:** Save and retrieve previous content reviews from Supabase.
- **Analytics Dashboard:** View review totals, findings, priority levels, and review decisions.
- **Human Review:** Support informed decisions before content is published.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Google Gemini API
- Supabase PostgreSQL
- Vercel
